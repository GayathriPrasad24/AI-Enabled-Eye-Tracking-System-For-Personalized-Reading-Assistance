👁️ Eye Tracking System

A real-time Eye Tracking Project built using Machine Learning and Computer Vision techniques to detect and track eye movements through a webcam. The system analyzes eye movement patterns for applications like accessibility support, healthcare monitoring, human-computer interaction, and smart surveillance.

🚀 Features
Real-time eye tracking
Eye movement detection
Webcam-based implementation
Machine Learning integration
Lightweight and efficient system
🛠️ Technologies Used
Python
OpenCV
NumPy
Machine Learning
Mediapipe / Dlib

💡 Applications
Assistive technologies
Driver drowsiness detection
Healthcare monitoring
Gaming & interaction systems
